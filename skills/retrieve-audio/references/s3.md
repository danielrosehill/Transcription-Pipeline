# S3-compatible buckets (AWS S3, MinIO, Wasabi, Cloudflare R2, Backblaze B2)

Use the CLI or remote the preferences name.

```bash
# aws CLI (add --endpoint-url for non-AWS providers, e.g. https://s3.wasabisys.com or your MinIO URL)
aws s3api list-objects-v2 --bucket <bucket> --prefix <prefix> --query 'reverse(sort_by(Contents,&LastModified))[:5].[LastModified,Key]' --output text
aws s3 cp s3://<bucket>/<key> ./

# rclone
rclone lsl <remote>:<bucket>/<prefix> | sort -k2,3 -r | head -5
rclone copy <remote>:<bucket>/<key> ./
```

For AssemblyAI you need not download at all: presign the object and pass the URL to `transcribe.py`.
```bash
aws s3 presign s3://<bucket>/<key> --expires-in 3600        # or: rclone link --expire 1h <remote>:<bucket>/<key>
```
